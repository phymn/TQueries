# TQueries

**v0.5.4 · Gemma**

SQL from a table screenshot. On this machine.

SQL Server · MySQL · PostgreSQL · SQLite · Oracle · Access

Apple Vision and Apple Foundation Models on macOS.
Gemma 4 E4B through Ollama.
Everything runs locally.

## Start

Double-click **Start TQueries.command** (Mac) or **Start TQueries.bat** (Windows).

Opens at http://127.0.0.1:4321

## Requirements

- Node.js
- Ollama
- `ollama pull gemma4:e4b`
- macOS 26 or later, for the Apple features
